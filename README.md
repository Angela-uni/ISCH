# MonteCristo
Repository of Information Science and Cultural Heritage course, held by Professors Francesca Tomasi and Marilena Daquino within the Master's Degree Programme in Digital Humanities and Digital Knowledge, Alma Mater Studiorum - Università di Bologna.
Created by Angela Paganini.

### Description of the project
---
A Linked Open Data model for fifteen entities selected from the Wikipedia page dedicated to _The Count of Monte Cristo_ by Alexandre Dumas. The project workflow is as follows:
- selection of the entities;
- categorize the entities and provide a link to their authority source \(e.g. VIAF, Wikidata, Geonames, etc.)\;
- creation of a theoretical model to visualize the relationships between the entities and their hierarchy;
- creation of a conceptual model leveraging existing ontologies such as CIDOC-CRM, FRBRoo, DCTerms, etc.;
- sample of the Wikipedia page used as reference for the project in XML/TEI syntax;
- creation of an XSLT file and of a Python script for transforming the XML/TEI page into an HTML page;
- creation of the RDF dataset in Turtle format.
